# repairs-tracker
System created thinking on tracking the repairings carried out by different concessionaries and thinking on real follow-ups for the clients of the concessionaries 

The idea of this project is to have a system that integrates the different actions that are taken by the mechanic in the concessionaries, save them, and query the status of the maintenance carried out by the company. Initially is though in cars however the idea is scalate for having it also for aerospatial parts
